# Historical Artifact Library

This directory is the public archive for historical working artifacts that document how the campaign-simulation approach evolved.

These files are evidence of development history, not current Campaign-Simulation authority.

## Naming

- `(original)` = the actual recovered historical working artifact, preserved in its original language and structure.
- `(legacy)` = an English publication translation of a recovered original artifact.

A legacy translation must carry this provenance:

> English Translation — Original Working Artifact
>
> Translated for publication. Structure and mechanics preserved from the original Greek working document.

Do not silently modernize, repair or retrofit historical mechanics inside a legacy translation. If a historical artifact contains an old rule, awkward structure or abandoned idea, that is part of the fossil.

## Intended organization

Artifacts should be grouped by evolutionary stage and ordered chronologically where evidence permits. Initial target stages:

1. early campaign / Combat Simulator material
2. Missions 1–9 experiment material
3. Mission 10 primers / handoff documents
4. Robbert Incorporation document-era simulation material

Do not invent missing artifacts or claim precise dates that cannot be verified.

## Public-safety gate

Before an artifact is added to this library, audit it for private data, local paths/usernames, emails, API responses, secrets/tokens, project identifiers where sensitive, comments/suggestions, hidden document metadata, raw chat material and campaign information that is intentionally private.

The private Mission 10 live repository is not mirrored here. Only deliberately selected historical artifacts belong in this library.
